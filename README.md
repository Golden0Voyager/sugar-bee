# 🍯 Sugar Bee (Glucose Tracker)

> **"Quantify your life, manage your metabolic health."**

这是一个独立的血糖追踪与分析应用，专注于提供移动端友好的血糖数据管理、AI 智能分类以及多维度的健康指标概览。

### 🚀 核心特性
- **模块化架构**：已完成 Blueprint 重构，支持高效的模块化开发。
- **多维度记录**：支持血压、体重、运动及血糖数据的多条记录切换与渲染。
- **AI 驱动**：集成 LLM 逻辑，优化饮食记录分类与逻辑判断。
- **移动端适配**：深度优化 iPhone 访问体验，解决复杂表单的数据错位问题。
