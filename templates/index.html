iOS 捷径搭建指南
什么是「快捷指令」？这是 iPhone 自带的 App，可以让你自动化一些操作。我们用它来读取你的绑定码并发送给服务器完成设备绑定。
打开「快捷指令」App

在 iPhone 上找到并打开「快捷指令」App（蓝色图标，有重叠的彩色方块）。

如果找不到，可以在主屏幕向左滑动，在搜索栏输入「快捷指令」。

创建新捷径
  1. 点击右上角 「+」 按钮创建新捷径
  2. 点击顶部「新快捷指令」，可以改名为「Sugar Bee 绑定」
添加 5 个操作

点击底部 「添加操作」，按顺序添加以下 5 个操作：

1
获取剪贴板
搜索「剪贴板」→ 选择「获取剪贴板」
作用：自动读取你复制的 6 位绑定码
2
词典
搜索「词典」→ 选择「词典」
点击「添加新字段」：
· 键（Key）输入：code
· 值（Value）：点击输入框 → 选择上方的 「剪贴板」 蓝色药丸
作用：把绑定码包装成 JSON 格式
3
URL
搜索「URL」→ 选择「URL」
输入以下地址：
http://192.168.1.72:5001/api/v1/health-sync/bind_from_shortcut
⚠️ 如果你的服务器地址不同，请修改为实际地址
4
获取请求内容
搜索「获取请求」→ 选择「获取 URL 内容」
配置：
· 方法：选择 POST
· 请求体：选择 JSON
· 点击「JSON」字段 → 选择变量 ②「词典」（蓝色药丸）
作用：向服务器发送绑定请求
5
显示提醒
搜索「提醒」→ 选择「显示提醒」
标题：输入 绑定结果
内容：选择变量 ④「获取 URL 内容」（蓝色药丸）
作用：显示服务器返回的绑定结果
推荐方式：直接下载捷径

点击页面上的「下载捷径」按钮，在 iPhone 上打开下载的文件，会自动跳转到「快捷指令」App 并提示添加。

添加后，只需复制绑定码 → 运行捷径 → 完成绑定。

常见问题

请确认：
1. iPhone 和服务器在同一局域网
2. URL 中的 IP 地址和端口正确
3. 服务器正在运行（uv run python app.py）

在 iPhone 上点击下载链接后，选择「在快捷指令中打开」。如果仍然无法打开，可以使用上方的「手动搭建」方式创建捷径。
