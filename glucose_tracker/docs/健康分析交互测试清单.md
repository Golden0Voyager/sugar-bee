## 🐛 常见问题排查

### 问题1：模态框不弹出
**检查**：
- Bootstrap JS 是否加载
- `#analysisOptionsModal` 是否存在
- 浏览器控制台是否有错误

### 问题2：Toast 不显示
**检查**：
- `showToast` 函数是否定义
- Bootstrap Toast 组件是否可用
- 浏览器控制台是否有错误

### 问题3：点击卡片无响应
**检查**：
- `selectAnalysisOption` 函数是否定义
- 网络请求是否成功
- 后端 `/analyze_health` 接口是否正常

### 问题4：页面不刷新
**检查**：
- `location.reload()` 是否执行
- setTimeout 是否正常
- 浏览器是否阻止刷新
