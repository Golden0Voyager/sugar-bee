## 使用建议

- 新增功能前请先按 [`CLAUDE.md`](../CLAUDE.md) 进入 Plan Mode 出方案。
- Plan Mode 原始文件保存在 `~/.claude/plans/`；定稿后建议同步一份到 `docs/plans/`。
- 实施完成后更新本文档及对应计划的“状态”列，避免已完成的计划误导后续开发。
